# Week 01 – Python Data Processing

## Overview

This project is a small Python data-processing application that loads a raw student dataset, cleans the data, and performs basic numerical analysis using NumPy.

The task focuses on practicing basic data loading, data cleaning, reusable functions, and numerical calculations in Python.

## Tasks Completed

- Loaded a raw CSV dataset
- Cleaned the dataset
- Handled missing and inconsistent data
- Removed duplicate records
- Converted data into appropriate data types
- Used functions for data-cleaning operations
- Used NumPy for numerical calculations
- Calculated basic statistics from the dataset
- Documented the process and results in a Jupyter Notebook
